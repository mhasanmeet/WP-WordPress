# Image Carousel Infinite Scrool

Elementor image carousel infinite scroll from left to right

select elementor `.swiper-wrapper` class from image carousel element

## Additional Options

* Pause on Hover = No
* Pause on Interaction = No
* Autoplay Speed = 0
* Infinite Loop = Yes
* Animation Speed = 5000
* Direction = Left / Right

## Code

```css

.swiper-wrapper{
    -webkit-transition-timing-function: linear !important;
    transition-timing-function: linear !important;
}

```
