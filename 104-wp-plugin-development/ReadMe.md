## WordPress Plugin Development

Before developing plugin we have something to concern;

* Decide which categories plugin to develop
* Check if your plugin name is common or unique. Try to make it unique. 
* Check your plugin name in wordpress.org/plugin
* Now we need to check plugin URL in wordpress.org/plugin, check preferred url if it available.
