# Taxonomies

Taxonomy is a grouping mechanism for all of the content that is created (by CPT, Custom fields, or WP default post types). It allows you to group your posts based on shared characteristics. WP default taxonomies;

* Category
* Tag
* Link_category
* Post_format

## Create Taxonomies by Plugins

Several Plugin offer CPT (custom post type) features

* Advanced Custom Fields
* CPT UI (Custom Post Type UI)
* Meta Box
* Crocoblock also offers custom post-type content
* JetEngine Post Types
* JetEngine Taxonomies

## Hierarchy

In taxonomies or CPT, the Hierarchical is a very important thing to do because by this we can make parent-child relationships within taxonomies or in CPT.
