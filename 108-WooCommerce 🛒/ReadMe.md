## WooCommerce Snippet
Here are some code snippets use to add extra functionality / features to WooCommerce pages and products. Use these php code snippets to `functions.php` file in theme / child theme folder. 

* Change **Add to cart** Button text in WooCommerce Shop page & Single product
* Redirect empty cart page to shop or any other page
* **add to cart** button click counter
* Product **Brand** Taxonomies in Shop / single product page
* WooCommerce Email add custom Cc & Bcc Recipient
