## WooCommerce Snippet
Here are some code snippets use to add extra functionality / features to WooCommerce pages and products.

## How to use this snippets to add extra functionality? 
Adding any kinds of code directly in WordPress core or theme will be **disaster**, because when there will be new updates for WordPress Core or for theme, any modification of code will be removed. To overcome this, we can depends on 

* Child theme (in `functions.php` file) or
* Plugin 

Where our custom code will be preserve.
